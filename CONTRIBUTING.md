# Contributing

This is a professional portfolio repository. Issues and pull requests that improve documentation, tests, or synthetic-data quality are welcome.

## Rules

1. Do not add real-world confidential data.
2. Do not invent measured accuracy claims.
3. Keep residual-risk scores paired with a non-empty rationale.
4. Run `python -m pytest tests/ -q` before opening a PR.
5. Map new controls to an existing NIST CSF 2.0 `category_id`.
